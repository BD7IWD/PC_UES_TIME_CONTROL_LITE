# 儿童电脑使用时长控制

> 一个 exe 搞定：家长用手机浏览器给孩子电脑定使用时长，时间一到屏幕直接"蓝屏"。

不需要服务器、不需要数据库、不需要联网、不需要注册账号。程序跑在孩子电脑上，你的手机连同一个 Wi-Fi 打开网页就能管。

**默认待机不打扰**——程序开机自启，但只有你在手机上点了「开始管控」才开始计时。你自己用电脑时它就是个安静的后台进程。

---

## 特性

- **单文件分发**：PyInstaller 打成 38 MB 的单个 exe，拷过去双击就能用，无需安装 Python
- **手机网页管理**：内置 HTTP 服务，手机浏览器访问 `http://电脑IP:8080`
- **手动启停**：默认待机；发现孩子在玩时点「开始管控」，自己用就点「暂停管控」
- **到点假装故障**：时间用完不做任何提醒，直接切到模拟 Windows 蓝屏；也可选「电脑已损坏」错误弹窗样式
- **防绕过**：屏蔽 Win 键 / Alt+Tab / Alt+F4 / Ctrl+Shift+Esc；进程被杀由守护进程拉起
- **用量防篡改**：SQLite + 注册表双写，删掉数据文件也清不掉当天已用的时间
- **家长后门**：手机点「解除锁定」，或在锁定画面上连点鼠标 10 次输入恢复密钥
- **可远程留言**：手机上发一句话，电脑端弹出 10 秒横幅

## 快速开始

### 1. 打包

```bat
build.bat
```

产物在 `dist\PCTimeControlLite.exe`。需要 Python 3.10+ 和 `pip install pyqt5 pyinstaller pillow opencv-python`。

### 2. 放到孩子电脑

把一个 exe 拷过去（建议 `D:\PCTimeControl\`），双击运行。右下角托盘会出现图标，没有主窗口。

> 首次运行 Windows 会弹防火墙提示，**必须点「允许访问」**，否则手机连不上。

### 3. 手机设置

手机连同一个 Wi-Fi，打开托盘右键菜单里显示的地址（如 `http://192.168.1.5:8080`），首次设置：

- 管理密码（≥6 位，登录手机页面用）
- 解锁密码（≥4 位，蓝屏解锁用）
- 每天允许使用多久

### 4. 平时怎么用

| 场景 | 操作 |
|---|---|
| 孩子在玩 | 手机首页点绿色大按钮「▶ 开始管控」 |
| 自己要用电脑 | 点「⏸ 暂停管控」 |
| 现在就不让玩 | 点「🔒 立即锁定」 |
| 时间到被锁 | 手机点「🔓 解除锁定」，或在蓝屏上连点 10 次输密码 |

## 工作原理

```
┌─────────────────── 孩子的电脑 ────────────────────┐
│                                                    │
│   PyQt5 托盘程序（无主窗口）                        │
│     ├── 计时器：读 SQLite 累计当日用量               │
│     ├── 内置 HTTP 服务 0.0.0.0:8080 ──┐            │
│     ├── 锁定画面（假蓝屏 / 假弹窗）    │            │
│     ├── 键盘钩子（屏蔽组合键）         │            │
│     └── 守护进程（被杀后拉起）         │            │
└───────────────────────────────────────┼────────────┘
                                        │ 同一个 Wi-Fi
                              ┌─────────┴─────────┐
                              │   家长手机浏览器   │
                              │  设置 / 启停 / 解锁 │
                              └───────────────────┘
```

- Web 线程只读写 SQLite，不碰 Qt 对象；主线程每秒同步状态，避免跨线程操作 GUI 崩溃
- 密码用 PBKDF2 加盐存储，会话 token 存内存，表单带 CSRF 校验
- 用量同时写 SQLite 和注册表 `HKCU\Software\PCTimeControlLite`，两边取最大值

## 已知边界

- **`Ctrl+Alt+Del` 拦不住**——这是 Windows 安全序列，用户态程序无法拦截。但用量按天累计，注销/重启回来照样锁
- **懂技术的孩子能破**：删掉 exe 或数据目录就没了。要彻底封死得改成 Windows 服务 + 禁用任务管理器（需要管理员权限）
- 手机和电脑必须在同一局域网；公司 Wi-Fi 若开启客户端隔离，请改用手机热点
- 受管电脑需允许 8080 端口入站（部分安全软件会拦，如已装需手动放行）

## 踩过的坑（供参考）

- **别用 6666 端口**：Chromium 系浏览器有「不安全端口」黑名单，6666 在里面，会直接报 `ERR_UNSAFE_PORT`，连请求都不发
- **对话框压不过全屏置顶窗口**：蓝屏是 `WindowStaysOnTopHint` 全屏，普通 `QInputDialog` 会被压在下面；且 `exec_()` 会自己重排窗口位置，`move()` 被覆盖，改用 `show()` + `QEventLoop`
- **QSS 背景会盖住 paintEvent**：给父窗口设了 `background` 时，自绘 widget 的文字会看不见，得在 `paintEvent` 里自己 `fillRect`
- **PyInstaller 单文件 + 频繁重启**：`%TEMP%\_MEI*` 残留积累后启动器清理孤儿目录会和新实例解压打架，报 `Failed to import encodings module`
- **PowerShell 5.1 读 UTF-8 无 BOM 脚本**：中文会乱码并破坏语法解析，`.ps1` 存成 UTF-8 with BOM
